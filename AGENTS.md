# Repository language

Use English for all repository content, including documentation, code comments,
command-line messages, generated reports, and commit messages.

Use Chinese when chatting with the user.

# Preserve algorithm behavior

Read the pinned official statement and verifier before evaluating a solution's
edge cases. Do not add branches for inputs excluded by the problem constraints.
For documentation and benchmark work, preserve library and solution algorithms
unless a reproducible failure on valid official input demonstrates a defect.
Do not make speculative correctness or defensive-programming changes.
